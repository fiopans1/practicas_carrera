# Practicas PP - Paradigmas de Programación

## Descripción
Prácticas de la asignatura de Paradigmas de Programación, explorando diferentes estilos de programación funcional.

## Lenguajes y Frameworks

- **OCaml** - Lenguaje funcional principal

## Contenido

- Programación funcional
- Recursión
- Funciones de orden superior (map, filter, fold)
- Pattern matching
- Tipos de datos algebraicos
- Evaluación perezosa
- Múltiples prácticas explorando conceptos funcionales avanzados
