# CIIE - Creación de Interfaces Inteligentes y Entretenimiento

## Descripción
Prácticas de la asignatura de Creación de Interfaces Inteligentes y Entretenimiento, enfocadas en el desarrollo de interfaces interactivas y videojuegos.

## Lenguajes y Frameworks

- **Python** - Lenguaje principal de programación
- **Pygame** - Framework para el desarrollo de videojuegos

## Contenido

- Desarrollo de un videojuego completo
- Editor de niveles
- Implementación de mecánicas de juego
