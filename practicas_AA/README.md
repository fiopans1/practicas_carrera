# Practicas AA - Aprendizaje Automático

## Descripción
Prácticas de la asignatura de Aprendizaje Automático, centradas en el procesamiento de señales de audio y técnicas de machine learning.

## Lenguajes y Frameworks

- **Julia** - Lenguaje principal para computación científica
- **Python** - Lenguaje auxiliar para procesamiento de datos
- **Librerías**: Procesamiento de audio, análisis de frecuencias, convolución

## Contenido

- Procesamiento de señales de audio
- Análisis de frecuencias (frecuencia de muestreo)
- Fragmentación de señales
- Convolución
- Cálculo de media y desviación
- Clasificación de sonidos (Minecraft sounds dataset)
