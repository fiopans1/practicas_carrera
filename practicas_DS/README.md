# Practicas DS - Diseño de Software

## Descripción
Prácticas de la asignatura de Diseño de Software, centradas en patrones de diseño, arquitectura de software y buenas prácticas de programación orientada a objetos.

## Lenguajes y Frameworks

- **Java** - Lenguaje principal de programación
- **IntelliJ IDEA** - IDE de desarrollo

## Contenido

- Patrones de diseño (Design Patterns)
- Arquitectura de software
- Programación orientada a objetos
- Refactorización de código
- Testing unitario
