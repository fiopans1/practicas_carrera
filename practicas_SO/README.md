# Practicas SO - Sistemas Operativos

## Descripción
Prácticas de la asignatura de Sistemas Operativos, enfocadas en la programación a nivel de sistema y gestión de recursos.

## Lenguajes y Frameworks

- **C** - Lenguaje de programación de sistemas
- **Make** - Sistema de construcción

## Contenido

- Gestión de procesos
- Gestión de memoria
- Listas dinámicas
- System calls de UNIX/Linux
- Programación de shells
- Manejo de señales
