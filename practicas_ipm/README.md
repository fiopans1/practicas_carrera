# Practicas IPM - Interfaces Persona-Máquina

## Descripción
Prácticas de la asignatura de Interfaces Persona-Máquina, enfocadas en el diseño e implementación de interfaces de usuario para diferentes plataformas.

## Lenguajes y Frameworks

### Desktop
- **Python** - Lenguaje principal para aplicaciones de escritorio
- **Tkinter/PyQt** - Frameworks de GUI

### Web
- **JavaScript** - Lenguaje para desarrollo web
- **HTML/CSS** - Maquetación y estilos

### Mobile
- **Flutter** - Framework multiplataforma para desarrollo móvil
- **Dart** - Lenguaje de programación de Flutter
- **Swift** - Para plataformas iOS/macOS

## Contenido

- Diseño de interfaces de usuario
- Prototipado y evaluación de usabilidad
- Desarrollo de aplicaciones desktop
- Desarrollo de aplicaciones web
- Desarrollo de aplicaciones móviles multiplataforma
