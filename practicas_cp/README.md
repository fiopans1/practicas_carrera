# Practicas CP - Concurrencia y Paralelismo

## Descripción
Prácticas de la asignatura de Concurrencia y Paralelismo, enfocadas en programación concurrente y paralela de alto rendimiento.

## Lenguajes y Frameworks

- **C** - Lenguaje principal de programación
- **OpenMP** - API para programación paralela en memoria compartida
- **MPI** - Interfaz de paso de mensajes para programación paralela distribuida

## Contenido

### Concurrencia
- Sincronización de hilos
- Mutex y semáforos
- Problemas clásicos de concurrencia

### Paralelismo
- Programación paralela con OpenMP
- Programación distribuida con MPI
- Optimización de rendimiento
- Análisis de speedup y eficiencia
