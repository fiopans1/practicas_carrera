# Practicas CGV - Computación Gráfica y Visualización

## Descripción
Prácticas de la asignatura de Computación Gráfica y Visualización, enfocadas en el desarrollo de gráficos 3D y animaciones.

## Lenguajes y Frameworks

- **C** - Programación de gráficos de bajo nivel
- **OpenGL** - API de gráficos 3D
- **Blender** - Software de modelado y animación 3D

## Contenido

- Renderizado 3D con OpenGL
- Modelado 3D en Blender
- Transformaciones geométricas
- Iluminación y sombreado
- Animación 3D
- Proyecto final: Modelado completo de un Ferrari
