# Practicas SI - Sistemas Inteligentes

## Descripción
Prácticas de la asignatura de Sistemas Inteligentes, enfocadas en el desarrollo de agentes inteligentes y sistemas basados en conocimiento.

## Lenguajes y Frameworks

- **Java** - Lenguaje principal de programación
- **IntelliJ IDEA** - IDE de desarrollo

## Contenido

- Desarrollo de agentes inteligentes
- Sistemas basados en reglas
- Búsqueda y planificación
- Razonamiento automático
