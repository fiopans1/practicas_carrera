# Practicas de Algoritmos

## Descripción
Prácticas de la asignatura de Algoritmos, enfocadas en el diseño, análisis y implementación de algoritmos eficientes.

## Lenguajes y Frameworks

- **C** - Lenguaje principal de programación
- **Make** - Sistema de construcción

## Contenido

- Análisis de complejidad algorítmica
- Algoritmos de ordenación
- Algoritmos de búsqueda
- Estructuras de datos avanzadas
- Algoritmos greedy
- Programación dinámica
- Divide y vencerás
- Backtracking
