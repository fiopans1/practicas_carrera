# Practicas TC - Teoría de Computación

## Descripción
Prácticas de la asignatura de Teoría de Computación, enfocadas en autómatas, lenguajes formales y computabilidad.

## Lenguajes y Frameworks

- **OCaml** - Lenguaje funcional para implementación de autómatas y máquinas abstractas

## Contenido

- Autómatas finitos
- Expresiones regulares
- Gramáticas formales
- Máquinas de Turing
- Teoría de lenguajes formales
- Computabilidad
