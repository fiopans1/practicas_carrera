# Practicas PL - Procesadores de Lenguaje

## Descripción
Prácticas de la asignatura de Procesadores de Lenguaje, enfocadas en el diseño e implementación de compiladores y analizadores léxicos/sintácticos.

## Lenguajes y Frameworks

- **Lex** - Generador de analizadores léxicos
- **Yacc** - Generador de analizadores sintácticos
- **C** - Lenguaje para implementación de compiladores

## Contenido

- Análisis léxico (tokenización)
- Análisis sintáctico
- Construcción de árboles de sintaxis abstracta (AST)
- Generación de código
