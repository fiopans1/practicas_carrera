# Practicas DLP - Diseño de Lenguajes de Programación

## Descripción
Prácticas de la asignatura de Diseño de Lenguajes de Programación, enfocadas en la implementación de intérpretes y compiladores.

## Lenguajes y Frameworks

- **OCaml** - Lenguaje funcional para implementación de intérpretes
- **OCamllex** - Generador de analizadores léxicos
- **Menhir/OCamlyacc** - Generador de analizadores sintácticos

## Contenido

- Intérprete de Cálculo Lambda (Lambda Calculus)
- Analizador léxico (lexer)
- Analizador sintáctico (parser)
- Evaluación de expresiones lambda
