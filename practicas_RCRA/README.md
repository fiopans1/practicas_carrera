# Practicas RCRA - Representación del Conocimiento y Razonamiento Aproximado

## Descripción
Prácticas de la asignatura de Representación del Conocimiento y Razonamiento Aproximado, enfocadas en técnicas de inteligencia artificial y resolución de problemas mediante constraint programming.

## Lenguajes y Frameworks

- **Python** - Lenguaje principal de programación
- **Librerías de IA**: Sistemas de constraints, búsqueda heurística

## Contenido

- Programación por restricciones (Constraint Programming)
- Resolución de problemas con XP
- Algoritmos de búsqueda
- Razonamiento aproximado
