# Practicas ISD - Ingeniería de Sistemas Distribuidos

## Descripción
Prácticas de la asignatura de Ingeniería de Sistemas Distribuidos, enfocadas en el desarrollo de aplicaciones distribuidas y servicios web.

## Lenguajes y Frameworks

- **Java** - Lenguaje principal de programación
- **Spring Framework** - Framework para desarrollo de aplicaciones empresariales
- **Apache Thrift** - Framework RPC para servicios escalables
- **Maven** - Gestión de dependencias y construcción

## Contenido

- Arquitectura de sistemas distribuidos
- Servicios web (REST/SOAP)
- RPC con Apache Thrift
- Cliente-servidor
- Gestión de transacciones distribuidas
- Middleware
